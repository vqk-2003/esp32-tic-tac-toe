## Tic Tac Toe Game running on ESP32 S3

Binary crate:
> tic-tac-toe 

Library crate: 
> game

Connection:
- Joystick Module:
    - GPIO09 -> VRX
    - GPIO10 -> VRY
    - GPIO11 -> SW

- TFT LCD ST7735S Module:
    - GPIO01 -> SCL
    - GPIO02 -> SDA
    - GPIO40 -> CS
    - GPIO41 -> RST
    - GPIO42 -> DC

## Current status: Playable (Only support two player mode currently)
